ASME B31.3 Process Piping sets the standard for weld inspection in most industrial piping systems. Here's a practical checklist QC managers can use on every project.

## Pre-Weld Inspection

- [ ] **WPS verified** — Welding Procedure Specification matches the joint requirements (base metal, filler, position, preheat)
- [ ] **Welder qualified** — PQR on file, stamp verified, cert not expired
- [ ] **Material verified** — MTR on file, heat number matches pipe/fitting
- [ ] **Joint fit-up approved** — gap, alignment, bevel angle within tolerance
- [ ] **Preheat applied** (if required by WPS)

## In-Process Inspection

- [ ] **Root pass visually acceptable** — no cracks, porosity, lack of fusion visible
- [ ] **Interpass temperature controlled** (if required)
- [ ] **Cap pass clean** — no undercut exceeding B31.3 limits (1/32" or 12.5% of wall)

## Post-Weld Visual Inspection (VT)

Per B31.3 §341.4.1:

- [ ] No cracks
- [ ] No incomplete fusion
- [ ] No crater cracks
- [ ] Reinforcement ≤ limits in Table 341.3.2
- [ ] Undercut ≤ 1/32" for t < 1/4"; depth ≤ wall × 12.5% for t ≥ 1/4"
- [ ] No exposed porosity > 1/16"

## NDE Requirements (Normal Fluid Service)

| NDE Type | Minimum % |
|---|---|
| Random radiography or UT | 5% |
| Liquid penetrant (PT) or magnetic particle (MT) | As specified |
| Hardness testing | Per P-number requirements |

Category D fluid service may reduce requirements. Severe cyclic conditions increase them.

## Record Requirements

- [ ] Weld number logged
- [ ] Welder stamp recorded
- [ ] WPS number referenced
- [ ] NDE results attached
- [ ] Repair record (if applicable)
- [ ] Final acceptance signature
