Pipe offsets are one of the most common calculations a pipefitter makes on the job. Whether you're routing pipe around an obstacle or making a 45° turn to hit a new elevation, knowing how to calculate the travel, spread, and set saves time and prevents costly mistakes.

## What Is a Pipe Offset?

A **pipe offset** is when you need to move a pipe run from one plane to another — either horizontally or vertically — while maintaining flow continuity.

## Simple Offset (Two 45° Elbows)

The most common offset uses two 45° elbows:

| What you know | Formula |
|---|---|
| **Travel** (diagonal pipe length) | `Spread × 1.414` |
| **Spread** (distance between pipe centerlines) | `Travel × 0.707` |
| **Set** | Same as Spread for 45° |

**Example:** You need to offset a 4" pipe 12 inches.
- Travel = 12 × 1.414 = **16.97"**
- Cut your offset pipe to 16.97" minus the take-outs for both elbows

## Rolling Offset (Moving in Two Directions)

A rolling offset moves the pipe both horizontally and vertically at the same time.

**Formula:**
```
True Offset = √(Rise² + Roll²)
Travel = True Offset × 1.414 (for 45°s)
```

**Example:** Rise = 8", Roll = 6"
- True Offset = √(64 + 36) = √100 = **10"**
- Travel = 10 × 1.414 = **14.14"**

## Take-Out Values for Common Fittings

| Fitting | 45° Elbow Take-Out |
|---|---|
| 2" | 1¼" |
| 3" | 1⅝" |
| 4" | 2" |
| 6" | 2⅞" |
| 8" | 3½" |
